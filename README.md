# 📝 PHP Blog System

A complete Blog Management System developed using **Pure PHP**, **MySQL**, **Bootstrap 5**, and **JavaScript**.

This project was built for my personal portfolio to demonstrate backend development skills using core PHP without frameworks.

---

## 📖 About The Project

The PHP Blog System is a dynamic web application that allows users to register, log in, create blog posts, and manage content through an administrator dashboard.

The project follows a simple MVC-like folder structure and includes authentication, CRUD operations, image uploads, and database integration.

## ⚙️ Installation

### Requirements

- PHP 8+
- MySQL
- XAMPP / Laragon / WAMP

### Setup

1. Clone the repository.

```bash
git clone https://github.com/myahtutkhaung2711/PHP-Blog-System.git
```

2. Move the project into your web server directory.

Example:

```
xampp/htdocs/
```

3. Create a MySQL database.

4. Import the SQL file located inside:

```
sql/
```

5. Update your database configuration.

```
config/
```

6. Start Apache and MySQL.

7. Open:

```
http://localhost/PHP-Blog-System
```
